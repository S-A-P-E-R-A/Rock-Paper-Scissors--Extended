On a technicall perspective, the code uses multiple  functions in order to minimize the abount of code within the game. In fact, there are so many functions, that adding in a feature where you can make your own game mode is easy, since the way the game modes are used is through lists. An element in the list alwayse beats what comes after it, making a roundabout way to play rock paper scissors. Recently, a new dynamic mode was added where multiple elements can interact multiple times, comparable to the pokemon type-advantage system, which is also included in the game.
